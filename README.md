# 🕷️ Telegram B2B Lead Scraper in Python (Telethon)

A lightweight and fast Python web scraper for extracting business contacts (B2B leads, groups, channels) from Telegram based on specific keywords. Built with clean code and no heavy frameworks.

**Note:** This is a DEMO version limited to 50 results.

## 🚀 Features
* Extracts business groups and channels automatically.
* Uses Telethon for fast Telegram API interaction.
* Exports clean data to a CSV file.

## 💻 Installation

```bash
git clone [https://github.com/Vladim88888/telegram-b2b-lead-scraper.git](https://github.com/Vladim88888/telegram-b2b-lead-scraper.git)
pip install telethon
python demo_scraper.py
